# Pickers
URL: https://developer.apple.com/design/human-interface-guidelines/pickers
A picker displays one or more scrollable lists of distinct values. The exact values shown and their order depend on the device language. Includes date pickers (calendar view, numeric keypad entry).
Best practices: use for medium-to-long lists (a pull-down button for short lists; a list or table for very large sets). In iOS, a picker's height is roughly consistent with the keyboard; consider showing a picker in a location that's easy to reach.
Developer: Picker/DatePicker (SwiftUI), UIPickerView/UIDatePicker (UIKit).
