# Toggles
URL: https://developer.apple.com/design/human-interface-guidelines/toggles
A toggle lets people choose between a pair of opposing states (on/off), using a different appearance for each. Styles include switch and checkbox; different platforms use these differently.
Best practices: use to manage the state of content or a view; clearly identify the setting/view/content the toggle affects.
Platform considerations: iOS/iPadOS commonly use the switch style; macOS commonly uses checkboxes and switches. Developer: Toggle/ToggleStyle (SwiftUI), UISwitch (UIKit), NSSwitch/NSButton checkbox (AppKit).
