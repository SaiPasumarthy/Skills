# Maps
URL: https://developer.apple.com/design/human-interface-guidelines/maps
A map displays geographical data, supporting zoom, pan, rotation, annotations, overlays, routing, and standard/satellite/hybrid views.
Best practices: make your map interactive; avoid noninteractive elements obscuring the map; pick an appropriate initial region; adapt overlaid controls to the map's size and safe areas.
Adaptive relevance: maps often fill the screen/window and must respect safe areas; overlaid controls should adapt to size class and orientation (see Layout).
Platform considerations: iOS, iPadOS, macOS. Developer: MapKit.
