# Activity views
URL: https://developer.apple.com/design/human-interface-guidelines/activity-views
An activity view (share sheet) presents a range of tasks people can perform in the current context (sharing activities, actions like Copy and Print, quick access to frequently used apps).

ADAPTIVE NOTE: An activity view can appear as a SHEET or a POPOVER, depending on the device and orientation.

Best practices: reveal via an Action button; provide app-specific activities (listed before system-wide actions); people can edit the list of actions.
Platform considerations: iOS/iPadOS/macOS. Developer: ShareLink (SwiftUI), UIActivityViewController (UIKit), NSSharingServicePicker (AppKit).
