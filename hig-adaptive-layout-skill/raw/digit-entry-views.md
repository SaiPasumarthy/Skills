# Digit entry views
URL: https://developer.apple.com/design/human-interface-guidelines/digit-entry-views
A digit entry view fills the entire screen and prompts people to enter a series of digits (like a PIN) using a digit-specific keyboard.
Best practices: use secure digit fields for sensitive data; clearly state the purpose with a title and prompt.
Platform considerations: NOT supported in iOS, iPadOS, macOS, visionOS, or watchOS — this is a tvOS-only component. OUT OF SCOPE for iOS/iPadOS/macOS adaptive layout. Developer: TVDigitEntryViewController (TVUIKit).
