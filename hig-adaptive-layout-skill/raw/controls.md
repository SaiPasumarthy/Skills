# Controls (system experience)
URL: https://developer.apple.com/design/human-interface-guidelines/controls
A control provides quick access to an app feature from Control Center, the Lock Screen, or the Action button. A control is a button (performs an action, links into the app, or launches a camera experience) or a toggle (two states). People add controls to Control Center, the Lock Screen, or the Action button.
Anatomy: a symbol image, a title, and optionally a value.
Platform considerations: iOS, iPadOS. Developer: WidgetKit control widgets.
