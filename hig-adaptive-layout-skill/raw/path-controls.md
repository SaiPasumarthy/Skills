# Path controls
URL: https://developer.apple.com/design/human-interface-guidelines/path-controls

A path control shows the file system path of a selected file or folder (e.g. Finder path bar). Two styles: Standard (linear list; hides names between first and last items if too long to fit) and Pop up (pop-up-button-like).

## Best practices
- Use a path control in the window body, not the window frame (not in toolbars or status bars).

## Platform considerations
Not supported in iOS, iPadOS, tvOS, visionOS, or watchOS. (macOS-only component.)

Resources: File management. Developer: NSPathControl (AppKit).
