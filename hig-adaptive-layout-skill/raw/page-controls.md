# Page controls
URL: https://developer.apple.com/design/human-interface-guidelines/page-controls
A page control displays a row of indicator dots, each representing a page in a flat list; a solid dot denotes the current page. Dots are equidistant and clipped if too many fit.
Best practices: use to represent movement between an ordered list of pages (not hierarchical/nonsequential — use a sidebar or split view for complex navigation); center a page control at the bottom of the view or window.
ADAPTIVE NOTE: Because dots clip when they exceed the width, page controls adapt to available width; pair with a scroll view in page mode (see Scroll views).
Platform considerations: iOS, iPadOS. Developer: UIPageControl.
