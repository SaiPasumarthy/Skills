# Segmented controls
URL: https://developer.apple.com/design/human-interface-guidelines/segmented-controls
A segmented control is a linear set of two or more segments, each functioning as a button. Within a segmented control, all segments are usually EQUAL in width. Segments can contain text or images. Offers a single choice (or, in macOS, single or multiple choices).
Best practices: keep segment content consistent (all text or all images); keep the segmented control's size manageable — avoid too many segments (limited horizontal space; on iPhone, limit the number of segments so labels remain legible). iOS/iPadOS: consider a segmented control as an alternative to a tab view.
Developer: Picker with segmented style (SwiftUI), UISegmentedControl (UIKit), NSSegmentedControl (AppKit).
