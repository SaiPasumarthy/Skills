# Charts
URL: https://developer.apple.com/design/human-interface-guidelines/charts
Organize data in a chart to communicate information with clarity and visual appeal. Anatomy: marks (bar/line/point), plot area, axes, ticks, grid lines, labels, legend, titles/subtitles/annotations.

Best practices (adaptive-relevant):
- Establish a consistent visual hierarchy (data most prominent).
- In a COMPACT environment, maximize the width of the plot area to give people enough space. Ensure vertical-axis labels are as short as possible; consider describing units in a title, and place longer axis labels (category names) inside the plot area when it doesn't obscure info.
- Use a fixed or dynamic axis range depending on meaning.
- Align a chart with surrounding interface elements (align leading edges; display vertical grid-line labels on trailing side; consider shifting the Y axis to the trailing side).
- Make every chart accessible (VoiceOver, Audio Graphs); don't rely solely on color.

Platform considerations: No additional considerations for iOS, iPadOS, macOS, tvOS, visionOS. watchOS: avoid complex chart interactions.
