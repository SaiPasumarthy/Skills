# Printing
URL: https://developer.apple.com/design/human-interface-guidelines/printing
iOS, iPadOS, macOS, visionOS apps can integrate system print functionality.
Best practices: make printing discoverable in standard locations — a Print item in the macOS File menu; an iOS/iPadOS toolbar/action-sheet button; optionally a toolbar Print button on macOS. Present custom printer/document options if needed.
Developer: UIPrintInteractionController (UIKit), NSPrintOperation (AppKit).
