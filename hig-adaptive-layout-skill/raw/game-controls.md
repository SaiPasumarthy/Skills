# Game controls
URL: https://developer.apple.com/design/human-interface-guidelines/game-controls
A game can support physical game controllers or default system interactions (touch, remote, mouse/keyboard). Support default interaction methods too, because not every player has a controller, and players appreciate using the platform's native input.
Adaptive relevance: support multiple input methods and adapt on-screen controls to their presence/absence (touch controls vs connected controller). Largely games-oriented.
Platform considerations: all platforms except watchOS support physical game controllers. Developer: Game Controller framework.
