# Activity rings
URL: https://developer.apple.com/design/human-interface-guidelines/activity-rings
Activity rings show daily progress toward Move, Exercise, and Stand goals. In watchOS the element always contains three rings; in iOS it contains either a single Move ring or all three if an Apple Watch is paired.
Best practices: display Activity rings when relevant (health/fitness apps, especially those contributing to HealthKit); don't alter ring colors/meanings.
Platform considerations: primarily watchOS and iOS. (Largely a fitness component; minimal adaptive-layout relevance for macOS.) Developer: HealthKit / HKActivityRingView.
