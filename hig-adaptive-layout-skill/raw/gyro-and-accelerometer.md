# Gyroscope and accelerometer
URL: https://developer.apple.com/design/human-interface-guidelines/gyro-and-accelerometer
On-device gyroscopes and accelerometers supply data about a device's movement. Usable in iOS, iPadOS, and watchOS (tvOS can use gyroscope data from the Siri Remote).
Best practices: use motion data only to offer a tangible benefit; respect privacy; don't rely on motion as the only way to perform an essential task.
Platform considerations: iOS, iPadOS, watchOS. Developer: Core Motion.
