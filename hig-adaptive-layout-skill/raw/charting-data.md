# Charting data
URL: https://developer.apple.com/design/human-interface-guidelines/charting-data
Presenting data in a chart communicates complex information with clarity. A chart can range from a glanceable graphic to a rich interactive centerpiece. See Charts for the components.
Adaptive relevance: charts should adapt to the available width — in compact contexts, maximize the plot area and shorten axis labels (see Charts).
Best practices: highlight a few key insights; make charts accessible; let people interact when it adds value.
