# Augmented reality
URL: https://developer.apple.com/design/human-interface-guidelines/augmented-reality
AR blends virtual objects with the real world using the device camera (iOS/iPadOS ARKit; also visionOS). People reorient the device to explore objects, interact via gestures/movement, join multiuser AR.
Adaptive relevance: AR views typically fill the screen — design overlaid controls to respect safe areas and adapt to orientation; keep UI minimal so it doesn't obscure the camera scene. On-screen coaching/controls should adapt to device size.
Best practices: make the camera view full-screen; provide clear onboarding/coaching; keep controls unobtrusive.
Developer: ARKit / RealityKit.
