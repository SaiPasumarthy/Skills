# File management
URL: https://developer.apple.com/design/human-interface-guidelines/file-management
Document-based apps help people create/edit/save documents. People browse documents via Finder (Mac) or the Files app (iPhone/iPad/Vision Pro). watchOS/tvOS don't provide document browsing.
Best practices: use app menus and keyboard shortcuts for creating/opening files; support the document browser; on macOS follow standard File menu conventions (see The menu bar).
Adaptive relevance: document UIs (split views with a file list + detail) should adapt across window sizes and compact/regular width (see Split views, Layout).
