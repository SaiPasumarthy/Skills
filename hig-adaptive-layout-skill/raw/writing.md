# Writing
URL: https://developer.apple.com/design/human-interface-guidelines/writing
The words you choose are an essential part of the user experience. Determine your app's voice; create a list of common terms; write clearly and concisely.
Relevance to adaptive layout: concise, well-structured text truncates less and adapts better across screen sizes and Dynamic Type; write labels short (see Typography, Layout). Account for text length changes across localizations (see Right to left / Layout adaptability).
Platform considerations: all platforms.
