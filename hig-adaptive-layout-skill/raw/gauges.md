# Gauges
URL: https://developer.apple.com/design/human-interface-guidelines/gauges
A gauge displays a specific numerical value within a range. Uses a circular or linear path; standard style shows an indicator, capacity style shows a fill. An "accessory" variant (like watchOS complications) works well in iOS Lock Screen widgets and StandBy.
Platform considerations: iOS, iPadOS, macOS, watchOS. Developer: Gauge (SwiftUI).
