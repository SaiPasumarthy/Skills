# Token fields
URL: https://developer.apple.com/design/human-interface-guidelines/token-fields
A token field is a type of text field that converts text into tokens that are easy to select and manipulate (e.g. Mail address fields). Can present suggestions; a token can include a contextual menu.
Best practices: provide suggestions; let people select, reorder, and edit tokens.
Platform considerations: macOS (the related iOS/iPadOS concept is tokens in search fields — see Search fields). Developer: NSTokenField (AppKit).
