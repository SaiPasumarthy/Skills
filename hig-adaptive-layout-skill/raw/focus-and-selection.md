# Focus and selection
URL: https://developer.apple.com/design/human-interface-guidelines/focus-and-selection
Focus helps people visually confirm the object their interaction targets, supporting component-based navigation with a remote, game controller, or keyboard. Focusing an item often also selects it (except when auto-selection would cause a distracting context shift).
Platform-adaptive: different platforms communicate focus differently — iPadOS and macOS draw a ring around an item or highlight it; tvOS uses the parallax effect. Design focusable elements with enough spacing so focus rings/effects don't overlap (see Layout).
Platform considerations: iPadOS, macOS, tvOS. Developer: focusable / focused (SwiftUI).
