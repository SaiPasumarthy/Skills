# Spatial layout
URL: https://developer.apple.com/design/human-interface-guidelines/spatial-layout

NOTE: This page is explicitly "Not supported in iOS, iPadOS, macOS, tvOS, or watchOS" — it is a visionOS-only topic (Apple Vision Pro infinite canvas). OUT OF SCOPE for this iOS/iPadOS/macOS adaptive-layout skill. Retained only for completeness.

Covers visionOS concepts: field of view, depth (z-axis, occlusion, shadow), dynamic scale vs fixed scale (a point defined as an angle rather than pixels), centering content in field of view, indirect vs direct gestures, using the Digital Crown to recenter, 60 pt spacing between interactive elements.

Platform considerations: Not supported in iOS, iPadOS, macOS, tvOS, or watchOS.
