# Combo boxes
URL: https://developer.apple.com/design/human-interface-guidelines/combo-boxes
A combo box combines a text field with a pull-down button. People can enter a custom value or choose from a predefined list.
Best practices: populate the field with a meaningful default value from the list; use an introductory label; provide relevant choices; make sure list items aren't wider than the text field (avoid truncation).
Platform considerations: macOS (primarily). Developer: NSComboBox (AppKit).
