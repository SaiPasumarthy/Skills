# Web views
URL: https://developer.apple.com/design/human-interface-guidelines/web-views
A web view loads and displays rich web content (embedded HTML and websites) directly within your app (e.g. Mail shows HTML message content).

Best practices: Support forward and back navigation when appropriate (not on by default). Avoid using a web view to build a web browser (Safari is the primary way people browse).

Platform considerations: No additional considerations for iOS, iPadOS, macOS, or visionOS. Not supported in tvOS or watchOS.
Developer: WKWebView (WebKit).
