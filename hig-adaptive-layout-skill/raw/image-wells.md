# Image wells
URL: https://developer.apple.com/design/human-interface-guidelines/image-wells
An image well is an editable version of an image view (copy/paste, delete, drag a new image in).
Best practices: revert to a default image when necessary; make standard copy/paste menu items available.
Platform considerations: NOT supported in iOS, iPadOS, tvOS, visionOS, or watchOS — macOS-only component. Developer: NSImageView (AppKit).
