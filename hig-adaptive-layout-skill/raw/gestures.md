# Gestures
URL: https://developer.apple.com/design/human-interface-guidelines/gestures
A gesture is a physical motion that directly affects an object. People make gestures on a touchscreen, in the air, or on input devices (trackpad, mouse, remote, game controller). Every platform supports basic gestures (tap, swipe, drag) — precise movements vary per platform/input device.
Best practices: give people more than one way to interact (don't assume a specific gesture — support voice, keyboard, Switch Control); respect system gestures; avoid conflicting with system edge-swipe gestures (e.g. Home Screen indicator, Notification Center); reserve the screen edges for the system.
Platform considerations: all platforms; standard gestures differ per platform. Related: Accessibility, Standard gestures.
