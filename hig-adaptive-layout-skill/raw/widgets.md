# Widgets
URL: https://developer.apple.com/design/human-interface-guidelines/widgets
A widget provides quick access to essential glanceable information and focused interactions in additional contexts. Appears across contexts: Home Screen and Lock Screen (iPhone/iPad), desktop and Notification Center (Mac), Smart Stack (Apple Watch), etc.

ADAPTIVE NOTE: Widgets come in different SIZES — small accessory widgets on iPhone/iPad/Watch up to system family widgets including an extra large size on iPad, Mac, and Apple Vision Pro. Widgets ADAPT their appearance to the context in which they appear and respond to a person's device customization (e.g. Lock Screen accessory widgets, tinted/Dark Mode appearances). Design each supported widget size deliberately — don't just scale one layout.

Best practices: show glanceable, timely content; design a distinct layout for each supported size; adapt to light/dark and tint modes.
Platform considerations: iOS, iPadOS, macOS. Developer: WidgetKit.
