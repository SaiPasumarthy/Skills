# Offering help
URL: https://developer.apple.com/design/human-interface-guidelines/offering-help
Provide contextual help when necessary. Match help to the task: an inline view for simple tasks; a tutorial for complex/multistep tasks. Relate help to the current action; make it easy to dismiss.
Platform considerations: macOS Help menu (Help Book), tooltips on hover (macOS/visionOS); iOS/iPadOS help buttons/inline views.
