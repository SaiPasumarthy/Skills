# Steppers
URL: https://developer.apple.com/design/human-interface-guidelines/steppers
A stepper is a two-segment control to increase/decrease an incremental value. It sits next to a field that displays the current value (the stepper itself doesn't display a value).
Best practices: make the affected value obvious; consider pairing a stepper with a text field when large value changes are likely.
Platform considerations: No additional considerations for iOS, iPadOS, or visionOS. Not supported in watchOS or tvOS. Developer: Stepper (SwiftUI), UIStepper (UIKit), NSStepper (AppKit).
