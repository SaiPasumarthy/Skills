# Motion
URL: https://developer.apple.com/design/human-interface-guidelines/motion
Fluid motion conveys status, provides feedback, and enriches the experience. Many system components include motion automatically and adjust it in response to accessibility settings or input methods (e.g. Liquid Glass responds with greater emphasis to direct touch, more subdued with a trackpad).
Best practices: add motion purposefully; make motion optional — respond to the Reduce Motion accessibility setting by reducing or removing animation (see Accessibility). Use natural animations to ease transitions when layout adapts (see Layout: preserve a person's context).
Platform considerations: all Apple platforms. Developer: accessibilityReduceMotion.
