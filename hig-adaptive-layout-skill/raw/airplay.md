# AirPlay
URL: https://developer.apple.com/design/human-interface-guidelines/airplay
AirPlay streams media wirelessly from iOS, iPadOS, macOS, tvOS to Apple TV, HomePod, and AirPlay-capable TVs/speakers.
Best practices: prefer the system-provided media player (standard controls, chapter navigation, subtitles, closed captioning, AirPlay streaming); provide an AirPlay route button. Minimal adaptive-layout relevance.
Developer: AVKit / AVRoutePickerView.
