# Lockups
URL: https://developer.apple.com/design/human-interface-guidelines/lockups
Lockups combine multiple separate views (content view, header, footer) into a single, interactive unit. All three views expand and contract together as the lockup gets focus. Types: cards, caption buttons, monograms, posters.
Best practices: allow adequate space between lockups (a focused lockup expands); use consistent lockup sizes within a row or group.
Platform considerations: tvOS-only component (TVLockupView). Largely OUT OF SCOPE for iOS/iPadOS/macOS, but the "consistent sizes within a row/group" principle is broadly applicable.
