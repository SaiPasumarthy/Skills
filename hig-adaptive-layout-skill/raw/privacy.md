# Privacy
URL: https://developer.apple.com/design/human-interface-guidelines/privacy
Be transparent about privacy-related data/resources you require and protect the data people allow you to access. Provide privacy details for the App Store. Request permission in context with a clear rationale.
Best practices: request access only when needed and explain why; minimize data collection; use system privacy features (permission prompts). Minimal direct adaptive-layout relevance.
