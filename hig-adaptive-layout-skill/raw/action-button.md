# Action button
URL: https://developer.apple.com/design/human-interface-guidelines/action-button
The Action button gives quick access to favorite features on supported iPhone and Apple Watch models — run App Shortcuts or system functionality. People choose the function during setup or in Settings.
Best practices: expose your app's key function via an App Shortcut; keep it fast and predictable.
Platform considerations: iOS (supported iPhones), watchOS. Developer: App Intents.
