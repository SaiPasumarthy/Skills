# Loading
URL: https://developer.apple.com/design/human-interface-guidelines/loading
The best content-loading finishes before people are aware of it.
Best practices: show something as soon as possible (placeholder text/graphics/skeleton, replaced as content loads); let people do other things while content loads in the background; communicate progress for long operations (see Progress indicators).
Adaptive relevance: placeholder/skeleton layouts should match the final adaptive layout so content doesn't jump when it arrives.
