# Collaboration and sharing
URL: https://developer.apple.com/design/human-interface-guidelines/collaboration-and-sharing
Simple, responsive collaboration/sharing using system interfaces and Messages (share sheet, drop into a conversation). After collaboration begins, use the Collaboration button to communicate and manage details.
Adaptive relevance: the share sheet (activity view) adapts as a sheet or popover by device/orientation (see Activity views).
Best practices: use the system share sheet; provide a Collaboration button; keep sharing consistent.
