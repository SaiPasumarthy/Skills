# Playing haptics
URL: https://developer.apple.com/design/human-interface-guidelines/playing-haptics
The system can play haptics in addition to visual/auditory feedback. Components like switches, sliders, pickers play haptic feedback automatically on supported iPhone models; Apple Watch Taptic Engine; Mac Force Touch trackpad.
Best practices: use haptics purposefully and consistently with system patterns; pair with visual/audio feedback for accessibility (see Accessibility).
Platform considerations: iOS (supported iPhones), watchOS, macOS (Force Touch). Developer: Core Haptics.
