# Icons
URL: https://developer.apple.com/design/human-interface-guidelines/icons
An interface icon (glyph) expresses a single concept in ways people instantly understand — streamlined shapes and touches of color. Design custom glyphs or choose SF Symbols. Both use black and clear colors to define their shapes; the system can apply color.
ADAPTIVE NOTE: Prefer SF Symbols so icons scale automatically with Dynamic Type and adapt to weight/appearance (see SF Symbols, Typography).
Best practices: keep meaning clear; use consistent visual weight; provide RTL variants where meaning depends on direction.
Platform considerations: all platforms.
