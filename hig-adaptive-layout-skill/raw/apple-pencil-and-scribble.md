# Apple Pencil and Scribble
URL: https://developer.apple.com/design/human-interface-guidelines/apple-pencil-and-scribble
Apple Pencil offers pixel-level precision for notes, sketching, markup on iPad, and works as a pointer/UI interaction tool. Scribble enters text in any text field via on-device handwriting recognition.
Best practices: support expected marking behaviors; support double-tap/squeeze where available; let Pencil complement (not replace) touch.
ADAPTIVE NOTE: iPad apps should accommodate Apple Pencil as one of several input modes (touch, keyboard, pointer, Pencil) — see Designing for iPadOS.
Platform considerations: iPadOS. Developer: PencilKit.
