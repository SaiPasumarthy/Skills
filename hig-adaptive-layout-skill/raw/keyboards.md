# Keyboards
URL: https://developer.apple.com/design/human-interface-guidelines/keyboards
A physical keyboard can be connected to any device except Apple Watch. Mac users use one all the time; iPad users often do. Keyboard shortcuts (primary key + modifiers Control/Option/Shift/Command) speed up interactions. Apple defines standard keyboard shortcuts that work consistently across the system.
Best practices: support standard keyboard shortcuts; define custom shortcuts for app-specific commands; support Full Keyboard Access; in iPadOS, mirror macOS keyboard-shortcut patterns and surface them in the menu bar.
ADAPTIVE NOTE: When a hardware keyboard is attached to iPad, the virtual keyboard doesn't occupy screen space — layouts should adapt to the presence/absence of the on-screen keyboard.
Platform considerations: iOS, iPadOS, macOS. Developer: UIKeyCommand, Standard keyboard shortcuts.
