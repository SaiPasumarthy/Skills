# SF Symbols
URL: https://developer.apple.com/design/human-interface-guidelines/sf-symbols
Thousands of consistent, highly configurable symbols that integrate with the San Francisco system font, automatically aligning with text in all weights and sizes.
ADAPTIVE NOTE: Because SF Symbols use equivalent weights and scale with the system font, they automatically scale with Dynamic Type size changes — use them for interface icons that must grow with text (see Typography > Supporting Dynamic Type). Symbols provide RTL variants and localized symbols (see Right to left).
Rendering modes: monochrome, hierarchical, palette, multicolor. Availability of symbols/features varies by OS version. Don't use symbols in app icons/logos.
Platform considerations: all Apple platforms. Developer: Image(systemName:) (SwiftUI), UIImage(systemName:) (UIKit).
