# Undo and redo
URL: https://developer.apple.com/design/human-interface-guidelines/undo-and-redo
Undo/redo lets people reverse actions and explore safely. Help people predict the results and highlight what changed.
Best practices: label undo/redo with the target action (Undo Typing); on iOS support the shake-to-undo gesture and/or Edit menu items; on macOS use standard Edit > Undo/Redo with Cmd-Z/Shift-Cmd-Z.
Developer: UndoManager.
