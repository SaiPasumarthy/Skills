# Color
URL: https://developer.apple.com/design/human-interface-guidelines/color
The system defines colors that look good on various backgrounds and appearance modes, and automatically adapt to vibrancy and accessibility settings.
Best practices: avoid using the same color to mean different things; use color consistently; ensure sufficient color contrast; consider how color appears in both light and dark appearances and when accessibility settings (Increase Contrast, Reduce Transparency) are on.
System colors adapt automatically across light/dark appearance and accessibility settings — a key part of an adaptive interface.
Platform considerations: system color sets differ per platform (e.g. iOS/iPadOS semantic colors like systemBackground, label). Developer: Color (SwiftUI), UIColor (UIKit), NSColor (AppKit).
