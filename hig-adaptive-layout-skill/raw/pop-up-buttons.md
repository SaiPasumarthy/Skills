# Pop-up buttons
URL: https://developer.apple.com/design/human-interface-guidelines/pop-up-buttons
A pop-up button displays a menu of mutually exclusive options; after selection the menu closes and the button can update its content to indicate the current selection.
Best practices: use for a flat list of mutually exclusive options/states (use a pull-down button instead for actions, multiple selection, or submenus); provide a useful default selection; give people a way to predict options without opening.
Platform considerations: available across iOS, iPadOS, macOS, etc. Developer: Menu with a selection binding (SwiftUI), NSPopUpButton (AppKit).
