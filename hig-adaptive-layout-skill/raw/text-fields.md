# Text fields
URL: https://developer.apple.com/design/human-interface-guidelines/text-fields
A text field is a rectangular area in which people enter or edit small, specific pieces of text.
Best practices: use for a small amount of information (use a text view for larger text); show a hint/placeholder; use secure text fields for private data; to the extent possible, match the size of a text field to the quantity of anticipated text (helps people visually gauge how much to provide); show the appropriate keyboard type in iOS/iPadOS.
Developer: TextField/SecureField (SwiftUI), UITextField (UIKit), NSTextField (AppKit).
