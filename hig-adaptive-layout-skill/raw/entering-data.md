# Entering data
URL: https://developer.apple.com/design/human-interface-guidelines/entering-data
Make it easy for people to provide information without mistakes. Pre-gather as much as possible; support all available input methods so people can choose what works for them.
Best practices: get information from the system whenever possible (settings, permissions); be clear about the data you need (placeholder or introductory label); minimize required fields; show the appropriate keyboard.
Adaptive relevance: supporting all input methods (touch, keyboard, pointer, Pencil, dictation) and adapting the form layout to the on-screen keyboard is core to adaptive data entry.
